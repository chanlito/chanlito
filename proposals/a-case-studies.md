## Selected work

### Loan origination platform

<samp>2026–now · Sean Oliver Consulting</samp>

Replaces a manual loan process, from the field agent's first visit through multi-level approval to disbursement. I own the architecture and delivery, work with the client in two-week sprints, and set the coding standards, tests and dev environment that new engineers onboard into.

<details>
<summary>Under the hood</summary>

- **Field app.** Android tablets, React Native and Expo. Works fully offline with encrypted SQLite drafts and background sync, GPS-tagged photos, ID OCR on the device, and a Khmer and English UI.
- **Approver portal.** React and TanStack. Review queue, decision history, delegation, configurable fields and dashboards.
- **API.** NestJS and TypeORM on Oracle. Microsoft Entra ID sign-in, refresh-token JWTs, audit logging, credit bureau checks and a server-side loan calculation engine.

</details>
