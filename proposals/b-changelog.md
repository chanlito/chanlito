## [2026.05] - Technical Lead, Sean Oliver Consulting

A loan origination platform for a Cambodian financial institution, replacing a manual process from field capture through multi-level approval to disbursement.

### Added

- Offline-first Android tablet app for field agents in React Native and Expo, with encrypted SQLite drafts, background sync, GPS-tagged photos, on-device ID OCR and a Khmer and English UI.
- Approver portal in React and TanStack with a review queue, decision history, delegation and dashboards.
- NestJS API on Oracle with credit bureau checks and a server-side loan calculation engine.

### Security

- Microsoft Entra ID sign-in over OIDC, refresh-token JWTs and audit logging.
