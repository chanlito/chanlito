# README design directions

Three mockups of the profile README in the chanlito.dev look, to compare before building one. Nothing here is live: the profile still shows the README at the root of `main`.

- [A, the notebook page](a/): the whole profile on one sheet of ruled paper, written on the 32px rules, with the pencil doodle of mini Chanlito drawing itself. Language tabs open a full Khmer or Spanish page.
- [B, stickers and real text](b/): a ruled hero page next to the waving 3D polaroid, then real Markdown with paper-label headings and pinned index cards. Khmer and Spanish fold out at the bottom.
- [C, pinboard](c/): no paragraphs, a collage of things to click: the polaroid, a name tag, a sticky note, a sticker sheet, index cards, passport stamps and an envelope.
